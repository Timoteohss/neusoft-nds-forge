# Triage labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for missing information |
| `ready-for-agent` | `ready-for-agent` | Acceptance criteria are complete and an agent can work independently |
| `ready-for-human` | `ready-for-human` | Requires a human decision or implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Apply `needs-triage` to newly created issues. Move to another role only as part
of an explicit triage decision.
