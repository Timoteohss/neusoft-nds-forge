# Domain documentation

This is a single-context repository. There is no `CONTEXT.md`, `CONTEXT-MAP.md`,
or `docs/adr/` yet; proceed using the maintained project documentation.

Before work on a stage, read `docs/stages.md`, `docs/adapter-contract.md`, and
the relevant sections of `docs/legacy-inventory.md` and `docs/validation.md`.
Treat `planned` stages as unimplemented. Experimental output is not a validated
Neusoft product. Keep OSM source provenance and capabilities explicit, and keep
native parser, SDK, UI preview, and guidance evidence as separate validation
levels.
