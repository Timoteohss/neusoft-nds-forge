# Issue tracker

Issues for this repository live in GitHub Issues at `Timoteohss/neusoft-nds-forge`.
Use `gh issue` from this checkout. New issues use the repository's triage flow
and carry `needs-triage` until reviewed. Do not copy proprietary investigation
artifacts, credentials, private device locations, or raw vehicle logs into an
issue. Reference external evidence by artifact type/hash only when the maintainer
has made it available to the assignee.
