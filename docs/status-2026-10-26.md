## 6. Causa raiz da busca de nomes (estado atual do conhecimento)

Sintoma no carro: digitar `Rua Luiz` → só POIs. Logs mostram `searchErrorCode 0`,
`Suggest Count 0`.

### 6.1 Caminho do engine (Ghidra + Frida)
- `nds_rt_getNamesOfLink(handle, key, &count)` (thunk arquivo `0x939f4`) →
  `FUN_001fa8c0` (arquivo `0xfa8c0`):
  - key: high32 = tileId, low16 = `(linkIndex<<1)|dir` (dir 0/1);
  - obtém o objeto de tile via vtable slot `0x100` em `[handle+8]`;
  - se o objeto for nulo → retorna 0;
  - senão lê atributos flexíveis por link (`FUN_001edc54`).
- Slot `0x100` = **`FUN_0020b7ac`** (arquivo `0x10b7ac`) — criador da NameAttributeLayer:
  ```
  key2 = (0xa00|UR, tileId)
  provider slot 0x28(key2)  → cache
  provider slot 0xf8(UR, tileId, &ptr, &len) → bytes da camada
  FUN_002d8b18(reader, ptr, len)         // 13-byte descriptor {u8 1, u64 ptr, u32 len}
  FUN_001ed314(tileId, versionByte, reader, &key2, &collector)
      └── FUN_00149c5c(reader, &key2, ...)   // AttributeMapList
  ```
  Loga `can not create NameAttributeLayer %x (UR %u)` se NULL.
- `FUN_00247698` (arquivo `0x147698`) é o chamador do leitor de mapa de nomes na busca
  por endereço; gate: `*(int*)(tile+0x330) < 0xb` → não consulta.
- `FUN_0023f824` (arquivo `0x13f824`) lê o atributo:
  - gate `[obj+0x330] < 0xb`;
  - lookup `(type=1, id=<u16 de contexto+0x2f98>)`;
  - itera linhas SQLite (100=ROW/101=DONE) e empilha `std::string`;
  - strings vêm de coluna SQLite (`FUN_002f9440` sobre statement em `obj+0x1a0`).

### 6.2 Dados

  - Nosso build Curitiba v10: **0/103**.

## 7. Formatos decodificados (para o encoder futuro)

### 7.1 Cabeçalho do tile ROUTE — `FUN_001e5e80` (arquivo `0xe5e80`)
- Lê máscara de **10 bits**; para version ≥ 3 alinha ao byte (6 bits de padding).
- Para cada bit 9→0 presente, lê u32 = offset em BYTES da seção (ordem [0]..[9]).
- Nosso encoder grava `(flags << 6)` em u16 + u32s; é compatível:
  `flags=0x183` → bits 8,7,1,0 → offsets [1],[2],[8],[9] = intersecções, links, máscaras, externos.

### 7.2 Seção 8 — nosso formato de máscara (aceito nativamente para attr 8)
```
var29 count
por descritor: 8 bits (valor 1), 16 bits attrId, 4 bits refType, 32 bits offset ABSOLUTO do grupo
padding até byte
grupo: 2 bits mode=0, var29 count, 6 bits reservados, entradas 2×u16 (intersection, mask)
```

### 7.3 AttributeMapList — `FUN_00149c5c` (arquivo `0x149c5c`)
- count: u8 (version<7) / u16 (version≥7)
- por mapa:
  - ids: version<7 → **um** id (u8, ou u16 se version≥0xd);
    version≥7 → u8 count + ids u16 (u32 se version≥0xd)
  - type: **4 bits**
  - offset: **u32** (offset do container; usado com `FUN_002d8b7c`)
- depois, para cada mapa: `FUN_002d8b7c(reader, offset)` e `FUN_00142c00(container)`.

### 7.4 Container de atributos — `FUN_00142c00` (arquivo `0x142c00`)
- version<7 (legado): attrId, type(<0xb), 4 flags, listas aninhadas + callback.
- version≥7: kind = u8, então:
  - kind 0: count → {attrId, value, refs, callback}
  - kind 1: grupos → {u16 refCount, refs, valores}
  - kind 2: itens → {switch 0..10, value, refs, callback}
- Callback: `tileCtx->vtable[0x10](ctx, attrId, value, reader, type, refs, bitOffset, subtype)`.

### 7.5 Codec de valores — `FUN_00146104` (arquivo `0x146104`)
- ids < 0x45c → jump table de 1116 entradas em `0x5575e0`.
- ids ≥ 0x4000 → switch: 0x4000 pares de bits, 0x4002 valor+extra, 0x4003 byte+bitoff+skip,
  0x4005 3 bits+2×u16, 0x4007 valor+flags, 0x4013 skips condicionais, 0x4001/0x4006 no-op.

### 7.6 Coletor — `FUN_001ec76c` (arquivo `0x1ec76c`; vtable AttrCollect em `0x5f72c8`)
- refTypes 0x90–0x98 = refs de nome; 0x99/0xD1 = marcador (bit 0x80000000);
  0xB6/0xBA = dados de número de porta (limite 1 MiB).
- slots da vtable: 0 = `0x1edbb4` (dtor), 1 = `0x1ee7e0` (deleting dtor), 2 = `0x1ec76c` (coletor).

### 7.7 Builder da camada — `FUN_001ed314` (arquivo `0xed314`)
- recebe (tileId, versionByte, reader, &key, allocator)
- layout in-memory (byte offsets):
  `0x00 u32 id`, `0x04 u8 type`, `0x08 u64 key`,
  `0x12 u8 defaultRefCount`, `0x13 u8 refKindMask`,
  `0x18 rel→A / 0x20 countA`, `0x28 rel→B / 0x30 countB`,
  `0x38 rel→C / 0x40 countC`, `0x48 rel→D / 0x50 totalRefs`,
  `0x58 rel→E / 0x60 countE`, `0x68 rel→F / 0x70 countF`,
  `0x78 u8`, `0x79 u32`, `0x7d u8`; arrays a partir de 0x80; ref u32 com kind em bits 20–22.
- loga `NameAttributeLayer %08x: too many name refs %u > %u (%u default, %u links, %u lines)`,
  limite 0xFFFF.

### 7.8 Reader descriptor — `FUN_002dfbc8` (arquivo `0x2dfbc8`)
- monta 13 bytes: `{u8 1; u64 dataPtr; u32 byteLen}`. O blob NÃO tem prefixo de versão.

### 7.9 Primitivas de leitura (bits, MSB-first)
- `FUN_002d9508` = 8 bits; `FUN_002d9460` = 4 bits; `FUN_002d9590`/`FUN_002d9d70` = 16 bits;
  `FUN_002d9660` = 32 bits; `FUN_002d9360` = 1 bit; `FUN_002d8c04` = offset atual em bits;
  `FUN_002d8b7c` = seek.
